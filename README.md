# Tetrate Homebrew tap

```sh
brew install tetrateio/tap/tetrate
```

The formula installs `tetrate`, the command for Tetrate products, on macOS (Apple silicon) and Linux (x86_64 and arm64). It also installs shell completion for bash, zsh and fish.

Each formula is generated by `tools/formula` in [tetrateio/releases](https://github.com/tetrateio/releases) from the manifest of a promoted release. It downloads the release files published there and checks their sha256 digests. Do not edit a formula by hand.
